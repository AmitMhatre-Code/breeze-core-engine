PB/SL — Reset warning states
Design mock for plan section 5.13. Hazard tiers, copy, and surfaces.
Reference
Hazard tiers
Derived server-side from the order book + live positions. Never stored — there is no sixth state to drift out of sync. Tier 3 is not a louder tier 2: different verb, different stake.
Chip Condition What is actually at stake Escalation
Reset No live orphans — all terminal Nothing. PB/SL simply stopped. Card only
Reset · 2 live Live orphans that still correctly close open legs Automation the user thinks is off will still act — but in the direction they originally intended. Card only
Reset · action needed An orphan whose leg is already closed, or reduced below the order qty Filling opens a brand-new position. App banner
Tier 1 is neutral, not amber — nothing is at stake, and colouring a benign reset amber trains the user to ignore tier 2 and 3. The gradient is neutral → amber → red.
