What is ICICI handoff?

Breeze Terminal never stores your ICICI Direct password. Signing in hands you off to ICICI's own login page over a secure session; once authenticated, ICICI issues a short-lived API token back to Breeze.

This token is what powers order placement, portfolio and market data — it expires daily and never grants withdrawal access.
